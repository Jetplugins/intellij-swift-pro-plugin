# Security policy

Do not report security vulnerabilities in public issues.

Use [GitHub's private vulnerability reporting](https://github.com/Jetplugins/intellij-swift-pro-plugin/security/advisories/new) to share the affected Swift Pro version, impact, reproduction steps, and supporting material privately with the maintainers.

Include the IDE and build, operating system, and relevant toolchain versions. Remove credentials, proprietary source code, personal information, and unrelated confidential information from reports and attachments.
